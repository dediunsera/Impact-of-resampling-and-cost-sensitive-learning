# Impact of Resampling and Cost-Sensitive Learning

This repository contains the code and experimental setup for analyzing the impact of data resampling techniques and cost-sensitive learning algorithms on predictive modeling, particularly in the context of highly imbalanced datasets.

## 📌 Research Overview
When dealing with imbalanced datasets, standard machine learning algorithms often struggle, biasing their predictions towards the majority class. This project investigates two primary approaches to mitigate this issue:
1. **Resampling Techniques:** (e.g., SMOTE, ADASYN, Random Undersampling) to balance the training data distribution.
2. **Cost-Sensitive Learning:** Modifying the learning algorithm to penalize misclassifications of the minority class more heavily than the majority class.

## 📂 Repository Structure
- `scripts/`: Python source code for data preprocessing, modeling, and evaluation.
- `results/`: Output logs, performance metrics, and comparison tables.
- `figures/`: Visualizations of model performance (e.g., ROC curves, Precision-Recall curves).
- `data/`: *(Private)* Directory for storing local datasets.
